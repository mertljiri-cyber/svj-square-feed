# Zeptat se na dům: zavedení a migrace

1. **Chat a autorizace** — UI `/zeptat-se`, Edge Function `ask-house`, vyhledávání a kvóta pod uživatelským tokenem. Výchozí stav vypnuto. Lokálně byly spuštěny testy s modelem nahrazeným testovací závislostí; skutečný Edge runtime a poskytovatel vyžadují integrační test s výslovně testovacím backendem.
2. **Mapa migrace** — `python3 scripts/wiki-migration-plan.py /cesta/k/vaultu` vypíše pouze ID, stránky a otisky; nedělá síťové požadavky ani zápisy. Výstup nesmí do veřejného Gitu. Před importem přečíst `AGENTS.md`, zkontrolovat celé povolené poznámky, převést lokální odkazy, odstranit soukromou korespondenci a osobní údaje. U každého výňatku spárovat manifestové PDF podle SHA-256 s aktuální verzí archivu stejného SVJ a ověřit fyzickou stránku. Bez jednoznačného párování výňatek nezveřejnit ani neposílat modelu.
3. **Import Markdownu** — schválené soubory nahrát do `svj-wiki-markdown` jako neměnné objekty podle `organization_id/note_key/content_sha256.md`, zaznamenat revizi a připravit výňatky bez přiděleného schválení. Schválení se uděluje až po ověření zdrojů. Privátní bucket a revizní tabulka existují v migraci; zapisovací nástroj/prohlížení revizí nejsou hotové. Nezavádět druhý živý vault. Souborová wiki s vydáními (dávkový import z allowlistu, wikilinky, odvolání): viz `15_SOUBOROVA_WIKI_RUNBOOK.md`.
4. **Ověření na testovacím backendu / UAT** — nastavit serverové `SVJ_AI_ENDPOINT` (HTTPS URL rozhraní chat completions), `SVJ_AI_KEY`, `SVJ_AI_MODEL` a až na ověřeném backendu `SVJ_AI_ENABLED=true` a frontendové `VITE_SVJ_ASK_ENABLED=true`. Klíč nikdy do `VITE_` ani Gitu. Se syntetickými daty prověřit přes skutečný prohlížeč výbor, vlastníka, cizí SVJ, znepřístupněný doklad, výpadek a kvótu. Citace otevírá konkrétní PDF a stránku. Pro zpracování reálných dat nejprve potvrdit poskytovatele a rozsah přenosu. Model nedostává uživatelský token ani přímá oprávnění k databázi.
5. **AI údržba** — samostatný proces s verzovaným postupem `AGENTS.md`. Nový zápis připraví návrh nové revize Markdownu a diff; výbor zkontroluje citace a změnu schválí. Změna se zařadí do indexu, stažený podklad nezůstane v odpovědích. Chat sám neuděluje práva ani nemění data. Historická rozhodnutí a aktuální evidence oprav jsou různé zdroje; čtecí dotazy nad aktuálními daty se přidávají jako explicitně povolené serverové adaptéry, ne jako volné SQL generované modelem. Export do Obsidianu je případný jednosměrný nástroj pro správce.
